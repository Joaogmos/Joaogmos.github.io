# joaogmos.github.io

Meu portfólio: uma página em HTML e CSS, sem framework e sem build, publicada pelo GitHub Pages.

- `index.html` e `style.css`: o site inteiro.
- `img/ecg-dii.webp`: derivação DII de um exame do CODE-15%, recortada da figura do [IAECG](https://github.com/Joaogmos/IAECG) e convertida para traço âmbar com fundo transparente.
- `cv.pdf`: currículo gerado pelo [repositório do currículo](https://github.com/Joaogmos/curriculo).

Para ver localmente, abra `index.html` no navegador.
